# 🌸 Iris Flower Classification

## 📌 Overview
This project builds a Machine Learning model to classify Iris flowers into **Setosa, Versicolor,** and **Virginica** using their physical measurements.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Project Workflow
- Load the Iris dataset
- Perform Exploratory Data Analysis (EDA)
- Visualize the data using Pairplot and Boxplots
- Train Logistic Regression and KNN models
- Evaluate models using Accuracy, Confusion Matrix, and Classification Report
- Compare models and select the best-performing one

## 📈 Result
Both models achieved high accuracy. The best-performing model was selected based on evaluation metrics.
